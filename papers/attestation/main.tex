% document, names no consumer concept, and names no realization mechanism.  What others

%
% VERSIONING:
%   v1.0.0 is a released specification.  Editions are immutable once published: a defect
%   fix or clarification bumps the version, and the anchor discipline holds — a
%   withdrawn claim removes its anchor rather than redefining it, so a consumer citing
%   it breaks instead of silently importing a changed meaning.  Change history lives in
%   version control, not in this file.
%
% FILE SET (10 section files + 2 appendices + 1 macro + 1 bib):
%
%   macros_attestation.tex ........ Root macros (v1.0.0); four export strata
%                                   [found]/[interface]/[surface]/[core]; the ONLY

%   references.bib ................ Bibliography (minimal: douceur2002sybil).
%
%   sections/00_title.tex ......... Title, abstract, motto (owns \setversion{v1.0.0}).

%                                        consumption discipline, clocks.

%                                        receipt in two classes, floor, constants,
%                                        phases, genesis, state.

%                                        transfer; cycle processing.

%                                        redemption, maturity conversion preserve it;
%                                        global non-decrease; burn-order residual.

%                                        cost decomposition, addresses and splitting.
