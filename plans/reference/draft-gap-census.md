# Draft-versus-implementation gap census

A clause-by-clause census of the four adopted drafts in `plans/drafts/`
against the incumbent decision records and the label checker as it is
written today. Each draft gets one table: the draft clause, its
disposition, and one line of evidence read from the code.

Draft clauses are named in plain code spans, never in parenthesized
citation form: the drafts are not yet an owner of this corpus, so a
citation of them would not resolve.
