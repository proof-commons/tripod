# Wave 1 bite-1.3 landing plan · `sec:w1b13:plan`

The initial study below proposed a sequence, not a disposition or authorization to change code; (`rec:w1b13:adoption`) now governs its proposals. It read `0.7.103-dev` and implements the handoff from (`rec:w1b12:closed`) toward (`proposal:wave1:bite-1-3`), (`task:guide15-exec:bite-1-3-deliverables`), (`setup:guide15-exec:bite-1-3-files-and-packages`) and (`gate:guide15-exec:bite-1-3-gate`). The governing mechanisms are rulings 160 and 161 at (`rule:phase7:wave1-realization-rulings`), with their acceptance recorded at (`rec:phase7:wave1-birth-admission`) and (`rec:phase7:wave1-keyed-admission`). No build, test or native execution was run for this study; its documentation gate checks the proposed packet, not an implementation.

**Disposition (Adopted sequence and decisions)** · `rec:w1b13:adoption`

The five-step sequence is adopted for bite 1.3. The four proposals are adopted: (`q:w1b13:entry`) uses a tapscript-owned immutable keyed bundle beside the Compact ASH bundle, with checked selection among published candidates and no second planner; (`q:w1b13:constructor`) stabilizes the typed leaf/recipe and curve capability in tapscript at step 3 and removes `keyed-constructor` with the vectors request, while transaction commitment/materialization stays in bite 1.4 and vectors' descriptor remains a conformance oracle; (`q:w1b13:evidence`) uses the bounded independent byte evaluator and explicit offline input contexts alongside unchanged admitted archives, with no native campaign while the recipe stays byte-identical; (`q:w1b13:handoff`) uses typed member/role context and parameterized resource formulas now, leaving serialized-input binding, full transaction bounds and the 1,564-handle bound with its N+1 refusal to bite 1.4. These dispositions govern the proposals below; their original wording records the reasoning.

## Starting boundary · `sec:w1b13:boundary`

The work starts with working fragments, not empty opcode implementations. `packages/tapscript/src/keyed_pattern.rs:26` emits born-first using the authenticated current input, drops the separate flags item, compares the four-byte spent-output index with zero and removes the remaining txid. `packages/tapscript/src/keyed_pattern.rs:74` compares output 0's full version/program pair with the authenticated current input's pair. Both leave no successful stack residue. `packages/tapscript/src/keyed_constructor.rs:65` already composes key-push/drop, both clauses and final true; `KeyedSemanticKey` accepts all 32-byte values, not only curve keys. Keep those bytes unchanged.

The compiler's default immutable plan exposes relation-owned runtime side/multiplicity, evidence and coverage (`packages/compiler/src/keyed_plan.rs:83`, `packages/compiler/src/keyed_plan.rs:90`, `packages/compiler/src/keyed_plan.rs:155`). SOURCE publishes four evidence obligations and no runtime carrier; MERGE publishes three evidence obligations and two clauses, each Input/EveryMember. The emission adapter must preserve these distinctions. SOURCE creates a keyed output recipe for a future spend; it does not execute its reader obligations or execute MERGE on the creation transaction.

The existing constructor is split: tapscript owns the leaf and supplied public curve capability, behind `keyed-constructor`; `packages/vectors/src/keyed_constructor.rs:123`, `:192` and `:217` construct, reconstruct and authenticate the experimental descriptor. It fixes SHA256 of the uncompressed generator as the NUMS derivation, one reviewed-version leaf, no siblings, and the Elements tagged domains. Transaction already owns public commitment helpers (`packages/transaction/src/taproot.rs:99`, `:113`, `:126`, `:459`). Do not introduce a tapscript-to-transaction dependency or copy the vector experiment into a second production constructor. The production constructor split needs the decision at (`q:w1b13:constructor`).

Static validation and measurement also exist: `packages/tapscript/src/stack.rs:539`, `:700` and `:1714` provide abstract execution, peak stacks and primitive resource sums; `packages/vectors/src/keyed_cost.rs:58` and `:109` project static costs and framed witness lengths. The static cost projection is not an independent oracle for itself. Existing admitted birth, continuation, constructor and cost archives remain evidence of their exact bytes; they do not become observations of a later production transaction merely by sharing a recipe.

## Stack and resource evidence for review · `rec:w1b13:resources`

These pins are written from the grammar, not regenerated from emitter output.
