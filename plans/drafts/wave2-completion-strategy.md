**Definition (Execution unit and size)** · `def:wave2:unit`

Each proposed bite has one input packet, bounded files/packages, performed checks, retained evidence and a stop condition. Small means one data/semantic boundary; medium means one operation or one enumerated compatibility question. These are scope classes, not elapsed-time promises. There are twelve bites, listed at (`sec:wave2:execution`), with former 2.3 split into 2.3a and 2.3b. To keep every landing buildable, 2.3a stages reviewed law bodies and local identity tests without activating public Relation/Kind/Subject variants; staged items are new public items or are reached from a non-test path, because the workspace denies `unused` (`Cargo.toml:117–118`, inherited at `packages/realization/Cargo.toml:25–26`) and a crate-private body reached only from tests fails the build as dead code, which applies equally to 2.2's extension; 2.3b activates that reviewed vocabulary atomically with all compiler/vectors consumers. New placement/layout algorithms remain Wave 3. Each code bite passes its lane gate and the full repository gate of record at import before the next landing. New files enter their nearest Meson census in the same bite.

**Definition (Common retained packet)** · `def:wave2:packet`

Every packet retains source clause and adopted ruling, exact changed-file list, canonical declaration/observation identities, controls and single-coordinate subjects, declared and observed refusal boundaries, results with exit codes and durations, per-battery resource deltas with the sampled cgroup's scope beside each wall, logs, changed/reused seam ledger, complete census by enumeration and explicit non-claims. Retain collateral changes such as a request/certificate identity separately from the semantic mutation. Model refusal, observation normalization refusal, declaration-validation refusal and conformance disagreement are different boundaries. Gates run beside other work on a shared node: retain load and own CPU, cgroup identity/scope and CPU/pressure/memory deltas beside each wall; mark unavailable samples explicitly. No check or acceptance predicate may depend on elapsed time. Trace new execution paths through structured spans/events; a printed report is not its own admission proof. Keep packet records under the adopted Wave-2 closure carrier and package tests as executable evidence.
